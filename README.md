# Anil Kumar — Interactive Portfolio

A responsive React portfolio inspired by a high-contrast black-and-white design, with the original blue suit portrait.

## Run locally

1. Install Node.js 18 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the localhost URL displayed.

## Publish

Run `npm run build`, then deploy the `dist` folder on Netlify or Vercel. You can also connect the GitHub repository to either platform for automatic deployments.

## Customize before publishing

- `src/main.jsx`: Update your name, experience, skills, projects, LinkedIn/GitHub URLs, and the placeholder `YOUR_EMAIL@example.com`.
- `public/anil-portrait.jpg`: Replace your portrait if desired.
- `src/style.css`: Edit fonts, colors, spacing and layout.
- The “My introduction” button currently opens an animated text introduction, not a talking video. Replace it with a real video once you record one.
- Project cards are conceptual visuals, not screenshots or links to completed project repositories.
- No resume was supplied, so a resume download is intentionally not wired up. Add your PDF in `public/` and link to it once ready.

## Note

The original photo is included as supplied. No claims about specific employer dates or project metrics are added beyond the available background. Review all details before publishing.
